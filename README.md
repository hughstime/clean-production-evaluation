# 危险废物焚烧处置清洁生产评价系统

## 项目简介

本系统是一款面向危险废物焚烧处置行业的清洁生产评价专业化工具，依据浙江省环保产业协会团体标准T/ZAEPI XXX—XXXX《危险废物焚烧处置行业清洁生产评价指标体系》，对危险废物焚烧处置企业的清洁生产水平进行定量评价与分级判定。

## 功能特性

### 核心功能
1. **四步式向导流程**
   - Step 1: 企业基本信息录入
   - Step 2: 39项指标数据填报
   - Step 3: 智能评价分析
   - Step 4: 专业报告生成

2. **智能评价引擎**
   - 隶属函数算法实现
   - 加权综合评分计算
   - 限定性指标"一票否决"机制
   - 自动等级判定

3. **可视化展示**
   - 雷达图展示8大类指标得分
   - 分项得分详细表格
   - 限定性指标检查结果
   - 改进建议自动生成

4. **报告导出**
   - PDF专业报告生成
   - 支持打印和本地保存
   - 包含完整的评价结果和分析

### 技术特点
- **纯前端架构**：所有计算在本地完成，数据不上传服务器
- **响应式设计**：支持桌面端和平板设备
- **离线使用**：支持数据本地存储，可离线操作
- **配置化设计**：指标体系可配置，便于标准更新

## 指标体系

### 8大类指标
1. **生产工艺及装备** (权重: 0.22) - 10项指标
2. **能源消耗** (权重: 0.12) - 1项指标
3. **水资源消耗** (权重: 0.06) - 1项指标
4. **原辅料资源消耗** (权重: 0.10) - 2项指标
5. **污染物产生与排放** (权重: 0.30) - 15项指标（含5项限定性指标）
6. **温室气体排放** (权重: 0.05) - 1项指标
7. **清洁生产管理** (权重: 0.15) - 6项指标
8. **资源循环利用** (权重: 0.10，加分项）- 3项指标

### 评价等级
- **Ⅰ级**: 清洁生产先进标杆水平
- **Ⅱ级**: 清洁生产准入水平
- **Ⅲ级**: 清洁生产一般水平
- **未达标**: 不满足Ⅲ级要求

## 使用说明

### 1. 企业信息录入
- 填写企业基本信息
- 系统自动保存到本地存储

### 2. 指标填报
- 选择Tab切换不同指标类别
- 定性指标：选择符合企业实际情况的等级
- 定量指标：输入实际测量数值
- 不适用选项：勾选后不参与评分

### 3. 评价分析
- 系统自动计算综合评价指数
- 生成雷达图展示得分分布
- 检查限定性指标达标情况
- 提供改进建议

### 4. 报告生成
- 生成完整的PDF评价报告
- 支持打印和导出
- 包含企业概况、评价结果、改进建议等

## 数据安全

- **本地存储**: 所有数据保存在浏览器本地
- **不上传**: 企业评价数据不发送到服务器
- **导出功能**: 支持数据导出为JSON/Excel格式
- **隐私保护**: 符合数据安全要求

## 配置说明

### 指标配置文件 (src/data/indicators.json)
包含完整的指标体系定义：
- 指标分类和权重
- 基准值设置
- 指标类型（定性/定量）
- 限定性标志

### 评价算法说明
- **隶属函数**: 将不同量纲的指标值映射为0-100分
- **加权求和**: 按类别权重计算综合得分
- **等级判定**: 根据得分和限定性指标确定等级

## 开发指南

### 添加新指标
1. 更新 `src/data/indicators.json`
2. 更新 `src/types/index.ts` 类型定义
3. 如需要，修改评价算法

### 修改评价标准
- 编辑 `src/data/indicators.json` 中的基准值
- 无需修改代码，系统自动适配

### 扩展功能
- 添加数据导入/导出格式
- 集成在线数据库
- 添加用户管理功能
